Once you are in the home page, there are a few things  you can see that you could do form the navigation bar  (the links at the top of the page)!:

- Library (Search for books) 
- Lists (You can add books) 
- Quiz (You can add/remove questions to make  a quiz) 
- login/sign up page if you are wanting to  create account! If you create an account, your Lists  (book lists) and quiz questions will be saved!
  
Note: Your added books in Lists and quizzes will not be  saved if you don’t have an account and the pages will  be empty once the page reloads! 

----------------------------------------------------------------------------------------------------------------------------------

Library 

In the Library, you can search for books! 

1. At the top of the page you will see a Search Box.
2. Type in a term and tap/click the search button (On laptop pressing Enter/Return button is not available).
3.  Lo and behold! Books related to the term will be  appear!

----------------------------------------------------------------------------------------------------------------------------------

Lists 

Note: Your added books in Lists will not save if you  don’t have an account and the pages will be empty if  you reload the page!

In Lists, you can add books that are reading to track  your last read chapter and add comments to the books! 

- Fill out the form - name of the book, author, chapter,  any comments you want to add  
- Click add book 
- The added book will appear at the bottom of the page. - if you want to remove it, there will be a Remove button. Click on Remove and click OK.
  
----------------------------------------------------------------------------------------------------------------------------------

Quiz 

Note: Your quiz will not save if you don’t have an  account and the page will be empty if you reload the  page! 

In Quiz, you can create questions and test yourself to  know the book better for a test or for fun! 

- In the Question Text, type in a question eg. What does  blood symbolise in Macbeth? 
- Add 3 incorrect answers and 1 correct answer in  Options A,B,C,D 
- Select the correct option. Eg. The answer is Guilt and  it was typed in slot Option A- the correct option you  select will be Option A. 
- Click Add Question to Quiz.  
- Repeat Steps 1-4 if you have multiple questions. - Once you are ready, at the top of the page click “Player  Mode” and start testing yourself!
